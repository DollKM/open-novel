在文件中执行精确的字符串替换。

用法：
- 在编辑前，你必须在对话中至少使用一次 `Read` 工具。如果未读取文件就尝试编辑，此工具将报错。
- 从 Read 工具输出编辑文本时，确保保留行号前缀之后的确切缩进（制表符/空格）。行号前缀格式为：行号 + 冒号 + 空格（如 `1: `）。该空格之后的所有内容才是要匹配的实际文件内容。切勿在 oldString 或 newString 中包含行号前缀的任何部分。
- 始终优先编辑代码库中的现有文件。除非明确要求，绝不创建新文件。
- 仅在用户明确要求时使用 emoji。除非被要求，避免在文件中添加 emoji。
- 如果文件中未找到 `oldString`，编辑将失败并提示 "oldString not found in content"。
- 如果 `oldString` 在文件中多次出现，编辑将失败并提示 "Found multiple matches for oldString. Provide more surrounding lines in oldString to identify the correct match."。请提供包含更多周围上下文的更大字符串使其唯一，或使用 `replaceAll` 更改每个 `oldString` 实例。
- 使用 `replaceAll` 跨文件替换和重命名字符串。例如，如果你想重命名变量，此参数很有用。
