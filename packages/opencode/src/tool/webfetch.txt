- 从指定 URL 获取内容
- 接受 URL 和可选的格式参数
- 获取 URL 内容，转换为请求的格式（默认为 markdown）
- 返回指定格式的内容
- 当需要检索和分析网页内容时使用此工具

使用说明：
  - 重要提示：如果存在另一个提供更好网页获取能力、更针对任务或限制更少的工具，请优先使用该工具而非此工具。
  - URL 必须是格式完整有效的 URL
  - HTTP URL 将自动升级为 HTTPS
  - 格式选项："markdown"（默认）、"text" 或 "html"
  - 此工具为只读，不会修改任何文件
  - 如果内容非常大，结果可能会被摘要
